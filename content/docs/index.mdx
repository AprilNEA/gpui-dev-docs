GPUI Developers publishes guides for community libraries built on [GPUI](https://www.gpui.rs), the GPU-accelerated UI framework behind the Zed editor. Each library writes its guides in its own repository, next to the code they describe; this site collects them under one navigation and one search. API references stay on [docs.rs](https://docs.rs).

Pick a library from the sidebar menu, or start from the directory below.

## Conventions

- Every library lives under `/docs/<name>`, for example `/docs/updater` for gpui-updater. The short form `gpui.dev/updater` redirects there.
- Search covers every library. Inside a library, results default to that library; use the filter at the bottom of the search dialog to widen or change the scope.
- Each page links to its source on GitHub and offers a Markdown copy for LLMs. The whole site is also available as [`/llms.txt`](/llms.txt) and [`/llms-full.txt`](/llms-full.txt).
